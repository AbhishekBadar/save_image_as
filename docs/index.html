Save Image As... — Privacy Policy

Chrome Extension

Overview

"Save Image As..." is a Chrome extension that allows users to convert and download images from web pages in various formats (PNG, JPG, WebP). Your privacy is important to us. This policy explains what data the extension accesses and how it is handled.

Data Collection

We do not collect, store, transmit, or share any personal data.

The extension does not use analytics, tracking, cookies, or any third-party services. There are no user accounts, no sign-ins, and no servers involved.

What the Extension Accesses

The extension accesses the following data solely to perform its core functionality:

  • Images on the current web page — to convert and download them when you explicitly request it via the right-click menu or the toolbar popup.
  • Image URLs — to fetch image data for format conversion. URLs are used locally and are never transmitted anywhere.

Permissions Used

  • contextMenus — to add the "Save Image As..." right-click menu.
  • downloads — to save converted images to your computer.
  • activeTab — to access images on the currently active tab when triggered by the user.
  • notifications — to show success or error messages after save/copy operations.
  • Host permissions (all URLs) — the content script needs to run on any webpage so it can access and convert images when you trigger the extension. It only activates on explicit user action.

How Data is Processed

All image processing (format conversion, resizing) happens entirely within your browser using the HTML5 Canvas API. No image data is ever sent to any external server. Converted images are saved directly to your local downloads folder.

Third-Party Services

This extension does not use any third-party services, APIs, libraries, or SDKs. It contains no ads and no affiliate links.

Data Storage

The extension does not store any data persistently. It does not use chrome.storage, localStorage, cookies, or any other storage mechanism. Each operation is independent and stateless.

Children's Privacy

This extension does not knowingly collect any information from children under 13. It does not collect information from anyone.

Changes to This Policy

If this privacy policy is updated, the changes will be posted on this page with a revised date below.
